# Wumms! Lebenszähler

Lebenspunkte-Zähler für 2–4 Spieler im Cartoon-Stil (Android).

## APK herunterladen
Jeder Push auf `main` baut automatisch eine neue APK.
Die neueste findest du unter **Releases** (rechts auf der Repo-Seite) → `Wumms-Lebenszaehler.apk`.

## Installieren
1. APK auf dem Handy herunterladen und antippen.
2. Android fragt einmal, ob Installationen aus dieser Quelle erlaubt sind → erlauben.

## App ändern
Die ganze App steckt in `app/src/main/assets/index.html`.
